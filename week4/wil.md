# Ch1. 나눈 화면에 반응을 더해요

React에서는 onClick 속성에 함수를 연결해 클릭 이벤트를 핸들링한다. 이때 함수명에 ()를 붙이면 함수가 화면을 만들 때 실행되어 버린다. 따라서 함수 이름만 {} 안에 넣어 변수처럼 전달한다. 
```
<button onClick={handleClick}>
```

# Ch2. React는 어떻게 기억할까요?

일반 변수의 값을 변경한다고 화면이 업데이트되지는 않는다. 이때 useState()을 사용한다. 초기화 방법은 다음과 같다. 
```
const [ liked, setLiked ] = useState(false);
```
이때 liked는 값을 읽는 데 사용되고, setLiked()는 변경을 요청한다. setLiked()를 이용해 변경이 요청되면 리액트는 컴포넌트를 다시 실행하고, 이때 새로운 값을 읽는다. <br>
한 번 더 눌렀을 때 취소되도록 구현하기 위해서는 화살표 함수 표현식을 사용한다. 
```
setLiked(previous => !previous);
```
이를 통해 setLiked()에 callback을 사용하면 첫 번째 인자로 이전 state 값을 전달받음을 알 수 있다. <br>
현재 선택에 맞게 다른 모양을 보여주기 위해서는 클래스를 사용한다. 
```
<button className={liked ? "like-button-is-clicked" : "like-button"}>
```

이때 props는 부모가 전달해주는 값이며, state은 컴포넌트가 스스로 관리한다. <br>
<br>
state와 실제 브라우저 기능을 맞추기 위해서는 useEffect()를 사용한다. 

# Ch3. 움직인다고 다 좋은 걸까요?
상호작용은 interaction, 그냥 움직임은 animation이라고 한다. 인터랙션을 통해 좋은 사용자 경험을 만들려면 화면을 가리거나 변화를 알아채기 어렵지는 않은지 확인해야 한다. 같은 사람이라도 상황에 따라 필요한 인터랙션이 다를 수 있다. 

# Ch4. 반응을 설계하는 감각
사용자의 목적을 생각하고 반응을 고르는 것이 좋다. 좋은 반응은 행동이 전달되었는지, 결과가 바뀌었는지 이해를 돕고 실수해도 돌아갈 수 있게 하는 등 부담은 줄인다. 

# 사용자의 행동에 반응하는 장면

### Discord
![Discord Interaction](./discordinteraction.gif)<br>
사용자가 음성 채팅 시, 소리 입력이 감지되면 사용자의 아바타 주위에 초록 원을 띄워 반응한다. <br>
사용자는 말을 상대에게 전달하기 위해 음성 채팅에 참여하고 음소거를 해제한다. 그러나 상대가 대답하기 전까지는 음성이 제대로 입력되고 있는지 알 방법이 없다. Discord는 아바타 주위에 초록 원이 뜨도록 설계해 이를 시각적으로 쉽게 확인할 수 있게 했다. <br>
이 반응은 어떤 시점에 음성이 제대로 입력되고 있는지 확인하기 위한 것으로, 시간 정보가 중요하기에 음성이 입력되는 동안만 정확하게 유지되어야 한다. 또한 대화가 계속해서 이어지기에 음성이 입력될 때마다 더 크거나 거슬리는 반응이 나타나면 불편을 야기할 수 있다.
