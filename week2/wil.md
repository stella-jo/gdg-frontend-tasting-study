# Ch2. React 떠먹기

React라는 라이브러리를 배웠다. 라이브러리는 도서관에서 필요한 책을 찾듯이 필요한 코드를 찾아 쓸 수 있는 코드의 모음을 말한다. React를 활용하면 화면 레이아웃을 html 구조와 유사하게 직관적으로 표현할 수 있다. 그러나 Javascript 구문도 포함해 사용할 수 있다는 장점이 있다. 이처럼 Javascript 안에서 UI를 표현할 수 있는 문법을 JSX라고 한다. 실습 파일에서는 Javascript 변수가 JSX 안에 어떻게 연결되는지와, 이를 통해 반복되는 코드의 효율을 높이고 변하는 값을 쉽게 관리하는 법을 배웠다. 또 이것저것 건드려 보다가 새로 추가한 태그에 이미 포함된 코드의 클래스명을 갖다 붙이면 디자인이 유사해지는 것을 확인할 수 있어 흥미로웠다.
